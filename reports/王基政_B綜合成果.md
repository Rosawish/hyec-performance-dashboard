# 王基政｜B 架構改用單一綜合成果錨點之暫評
日期：2026-11-14。供 Rosa 與評核網站整合審閱，不改站、不覆寫 R5 或原 Agent；屬內部 POC 專業建議，不是正式人事核定。

## 1. 本輪方法與結論
依最新要求，**取消營運、策略專案、會議追蹤各占 70%÷3 的算式**。三者只作同一份成果證據的不同入口，合併去重、確認 Q3 時間與處長責任後，以整體成果錨點給一次分數。

本輪判斷：**70% 綜合成果分 H＝4／9，S0、S5 都為 4；加權貢獻 2.80。** 其餘 30% 沿用本輪獨立複核的五項原權重與採分，B 總分為 **S0 3.28／9；S5 3.88／9**。

這次是新方法下獨立判斷仍落在 4，不是用三個舊 4 平均後換標籤。EGIS 等階段成果和具名交辦均已納入；沒有為了讓新方法看起來不同而任意增加分數。

## 2. 可重現的整體專業判準
採 1–9 分整數級距，不編造原 Agent 未定義的小數級距。本次操作化判準是明示的 POC 專業判準，**不是原 Agent 原文規則**。

審查順序：①以當季有效目標確認應交結果；②把同案會議、計畫、自報視為同一事件鏈；③分類實際成果、已證落差、尚未核實；④只取處長本人承接或事業處督導責任；⑤將整體落在最符合下列條件的一級，列出相鄰級距不適用原因。不以材料篇數、開會次數、列名次數投票。

|錨點|整體判定條件|
|---|---|
|1–2|主要責任大範圍未履行且有明確實證；不能因缺資料判到此級。|
|3|多項重要成果明顯落後，且現有可驗證推進不足以支持主要工作仍有實質進展；需說明整體受影響而非單一事件。|
|4|主要工作有可驗證的實質或階段成果，但重要營運結果與策略／執行交付仍有已證落差，尚不足認定整體主要要求基本達成。|
|5|可驗證證據足以支持主要當季要求基本達成；有待改善，但已證重大落差不再主導整體履行情形。未要求所有案均結案，長期研發以當季關卡判斷。|
|6|基本達成以外，主要交付品質、時效及獨立完成較穩定；需有明確交付或改善驗證，不能只靠追蹤條目。|
|7–9|有廣泛且持續超越要求、組織影響或突破的實證，依原量尺另判；個別成功接單或 NDA 不足單獨支持。|

**重要性判斷，不另偷偷配權重：**毛利／銷貨是處長核心經營責任；EGIS／低碳／數位化是明確年度策略，當季有到期節點者納入；一般追蹤與尚未到期計畫不與上述成果等量。此方法是有紀錄的整體裁量，不宣稱數學唯一答案。後續複評若結論不同，須指出變更的事件、責任或錨點，不得只填一個新數字。

## 4. 為何判 4，而不是 3、5 或 6
- **不是 3：**有實質接單成長及 GM 正面肯定，EGIS從合作重啟到技術資料取得，工時專案按計畫，其他數位化亦有實際進度。不能寫成只追蹤、沒有成果。
- **尚不支持 5：**不是因「沒資料就不好」，而是分潤後毛利額僅約65.47%及毛利率低於目標7.25百分點，且低碳樣盤與數個有明確計畫／實際的策略執行節點確有落差。EGIS正向里程碑不足將這些不同核心責任的已證差距抵成主要要求整體達成。仍未核的交辦／說明會不作額外扣分，只不拿來當達成證明。
- **不支持 6以上：**無足夠證據證明整體交付穩定、準時且優於基本要求。這不否定個別案的價值。

## 5. S0／S5 及完整 B 計算
本輪 H 已是依可用證據形成的單一有據判斷，不是缺值欄位。S5不能因未被批評的案子就把整體H覆蓋為5；S0也不因個別交付未核就把整體H歸零。**未另建立未知案件權重，亦未將缺證案平均稀釋到 H。**兩情境在H同為4，仍保留未知範圍；這不代表證據完整。若要求按每案S0/S5給分，須另定案件分母與重要性，那將是另一方法，不能冒充本次整體裁量。
